## 参照した条件

- [Leanny/splat3](https://github.com/Leanny/splat3): 確認したリポジトリのトップページでは、画像を本ツールに再配布・利用することを許すライセンスを確認できなかった。許諾が存在しないと断定したものではない。Leanny に許諾を確認できても、ゲーム画像に第三者の権利があれば別途考慮する必要がある。
- [Inkipedia の著作権案内](https://splatoonwiki.org/wiki/Inkipedia:Copyrights): 文章と画像の条件は別で、画像・メディアの条件は各ファイルのページによる。[ユノハナ大渓谷に相当するファイルのページ](https://splatoonwiki.org/wiki/File:S3_Stage_Scorch_Gorge.png) は著作権対象で、同サイトでのフェアユース等を記述する。この記述は本ツールでの再利用許諾ではない。このページの画像と手元の画像の同一性は未確認。
- [任天堂の配信ガイドライン](https://www.nintendo.co.jp/networkservice_guideline/ja/index.html): 適切な動画・静止画共有サイトへの投稿を対象とし、一般的な独立ウェブアプリ内の素材利用を包括的に許諾する内容ではない。通常のゲームプレイでは利用できない映像等をデータマイニングで抽出して利用する投稿にも言及がある。ただし本プロジェクトの画像がそれに該当するか、抽出元は確認できていない。
- 武器データ取得スクリプトは [stat.ink API](https://stat.ink/api/v3/weapon) を参照。画像とは別に、データや名称の再利用条件も確認する。stat.ink のソフトウェアのライセンスをそのままゲーム画像の利用許諾とみなさない。

## 対応案

1. サイトアイコンの作成経緯（自作、生成、第三者素材の利用の有無）を確認し、説明できなければ独自のロゴに交換する。イカの特徴を再現した図柄も、独自制作なら自動的に安全とは限らない。
2. 宣伝前のリスク低減を優先する場合、ステージ画像は名前と色分けした汎用背景に置き換え、武器・サブ・スペシャルは名前と武器種などの独自の汎用図形で表現する。名前検索・カテゴリ表示を維持して識別性を確保し、結果画像にも同じ方針を適用する。名称や独自に描いた図柄の権利・商標も別途検討する。
3. ゲーム画像の維持を希望する場合、画像ごとの元データ・権利者・利用条件・根拠を整理し、必要な権利者の許諾や専門家の確認を得る。Switch のスクリーンショットに差し替えるだけで、ウェブアプリ内の素材利用が許可されるとは判断しない。
4. 表示から外しても公開リポジトリや Git の過去履歴には画像が残る。必要な公開範囲の見直しは現状の公開状態を確認し、履歴変更や削除の影響を検討したうえで別途実施する。
5. 取得用スクリプト、書き出す結果画像、PWA アイコン、README も変更方針に合わせて確認する。置換後にコードの再利用ライセンスを設定する場合でも、第三者素材には別条件を適用する。

## 非公式サイトで確認できた例（2026-11-04）

- [sendou.ink](https://github.com/sendou-ink/sendou.ink): 武器・ステージなどの画像を[別の素材リポジトリ](https://github.com/sendou-ink/assets)で管理し、CDNから配信。アプリ本体のAGPLと、別リポジトリの画像の利用条件は分けて考える。公開情報から任天堂の許諾の有無を確認したものではない。
- [stat.ink](https://stat.ink/index?_lang_=ja-JP): 非公式表記があり、[hacceuee/s3-pixel-icons](https://github.com/hacceuee/s3-pixel-icons)を使用すると明記。ピクセル画像は制作者が非営利で他のプロジェクトに利用可能と案内し、[CC BY-NC 4.0](https://github.com/hacceuee/s3-pixel-icons/blob/main/LICENSE)を指定している。一方、制作者は任天堂の知的財産の利用許諾権限はないとも明記。配信画面や収益化動画への映り込みを含む具体的な利用の扱いは、必要に応じ制作者に確認する。
- [イカノート](https://splatoon-note.vercel.app/about): 非公式表記と制作者へのクレジットを記載し、Sunfish氏による図面について表示・非営利・継承の条件を示している。これらは実際のステージ風景ではなく図面。個別ライセンスの対象範囲や第三者の権利は別途確認する。
- [GameWith のステージ一覧](https://gamewith.jp/splatoon3/367747): ステージの画像を攻略記事内に掲載している例。画像の取得方法と任天堂との契約・許諾の有無は調査からは不明。他サイトで見られる事実は本ツールへの許諾にはならない。

素材を維持したい場合、Leannyに画像の取得・再掲載に関する意向、元の権利者、許諾根拠を確認する。ただし回答者が第三者の権利について許諾する権限を持つとは限らない。ステージは保存元URL・元ファイルの提供者を特定し、ゲーム内風景の再掲載について個別に確認する。Switch で自分で撮影した場合は他サイトからの転載という問題は避けられるが、ゲーム画像のウェブアプリ掲載が任天堂に許諾されるとは確認できていない。
