# 🦑 Splatoon Draft Tool

スプラトゥーン3向けのオンライン武器ドラフトツールです。ホストと参加者に分かれて、リアルタイムでBANとPICKを行えます。1人で両チームを操作して試せるソロモードもあります。

🔗 **[ツールを開く](https://splatoon-draft.vercel.app/)**　／　アプリ内の「📖 使い方」からも操作ガイドを読めます。

## クイックスタート

### マルチプレイ（最大8人）
1. ホストが「ホストとして部屋を作る」を選択
2. ホスト名を入力し、「自由に作る」または説明付きのプリセットを選ぶ
3. 表示されたルームID（またはURL）を参加者に共有
4. 参加者が「部屋に参加する」からルームIDを入力して入室
5. ホストがチーム編成を確認し「ドラフト開始」を押してスタート

### ソロ
1人で両チーム分を操作してドラフトを確認できます。ルールの試し・練習向けです。

### 🤖 botと試す（1人でマルチの動作確認）
- 「ひとりで試す」の「🤖 botと試す」から、botを参加者にしたテスト部屋を作れます。初期状態で設定人数ぶんのbotが入り、すぐ開始できます。
- 中身は通常のマルチの部屋と同じ仕組み（Firebase）で動くので、チーム分け・タグ・個人ピック・同時ピック・メンバードラフト・連戦・ステージ方式などを1人で確認できます。
- botは自分の番が来ると自動でランダムに選びます（BAN・PICK・ガチャ・ステージ選択・キャプテン指名・敗者のルール選択・トレードの応答）。動作はホストの端末が代わりに行います。
- ロビーの「BOTテスト部屋」欄でbotの追加・削除・速さ（速い／普通／ゆっくり）を変更できます。**完全オート**をONにすると、自分の番や連戦の勝者入力も自動で進みます（ドラフト画面の「🤖 オート」でも切替）。
- botの入った部屋のドラフトは、武器統計（匿名集計）にも「この端末」の統計にも記録しません。

> **開始できる人数**: 個人ピック・相手ピック・同時ピックは、両チームとも設定人数が揃うまで「ドラフト開始」が押せません。代表者ピック・ガチャ・BANのみは、各チームに1人以上いれば開始できます（例: 4v4設定でも2人で開始可）。ロビーには現在の参加人数が表示されます。

> **参加者の退出**: ホストはチーム分けの各メンバー横の「×」で、その参加者をロビーから退出させられます。

> **同じ端末での再参加**: チーム割り当て済みの参加者がページを閉じたり再読み込みしたりしても、同じ端末・同じブラウザで再入室すれば元のチーム枠（ピック順割り当て）に戻れます。再参加時に名前も変更できます。

## 機能

### ドラフトの基本（BAN / PICK）

#### BAN フェーズ
試合で使えない武器を事前に封じるフェーズです。BAN数は「なし〜各8」で設定できます（既定は各4）。

| モード | 説明 |
|---|---|
| 代表者BAN | 両チームが同時にBANを選んで送信。相手の選択は両者そろうまで伏せられ、揃った時点で一斉公開・確定されます |
| 個人BAN | ピック順上位のプレイヤーがそれぞれ担当のBANを送信。味方のBANはBAN中もチーム内で共有表示され、重複を避けられます（相手のBANは伏せたまま） |

- 武器やジャンルを1回タップすると仮選択、同じ項目をもう一度タップすると確定します。個人BANは確定と同時に送信され、代表者BANは必要数が揃うと自動送信されます。ソロは両チーム分のBANが揃うと次へ進みます。
- **ジャンルBAN**: 武器単位とは別枠で、武器種 / サブ / スペシャル単位のBANも設定できます。例えば「サブ＝2」にすると、サブを2種類まるごと禁止＝そのサブを持つ武器をすべて候補から外せます。個人BAN・相手ピック・「全員が武器ピック → チーム分け」では使えず、その場合は設定欄に理由が表示されます。

#### ピック順（7種類）
チームが武器を選ぶ順番です。

| ピック順 | 並び | 対応 |
|---|---|---|
| 交互 | 先攻→後攻→先攻… と1枚ずつ交互 | ソロ・マルチ |
| スネーク | 先1→後2→後2→先1→先1→先1（既定） | ソロ・マルチ |
| クラシックスネーク | 先1→後3→先3→後1 | ソロ・マルチ |
| ミドルスネーク | 先1→後2→後2→後2→先1 | ソロ・マルチ |
| バランス | 先1-2-1 / 後1-2-1 | ソロ・マルチ |
| 前重ね | 先2-1-1 / 後1-2-1 | ソロ・マルチ |
| 同時ピック | 両チームが同時に選択し4回一斉公開。被りあり | マルチ専用 |

#### ピックモード（5種類）
誰が、どの武器を選ぶかの方式です。

| モード | 説明 |
|---|---|
| 👥 個人ピック | 各プレイヤーが自分のターンに自分の武器を選択 |
| 🤝 代表者ピック | チーム代表者がチーム全員分をまとめて選択 |
| 🆚 相手ピック | 対になる相手プレイヤーの使用武器を選ぶ（相手が使う武器を自分が決める） |
| 🎲 ガチャ（運命ピック） | BAN後に人数分の武器がランダム配布される。チームごとに数回まで引き直し（リロール）でき、両チーム確定で結果へ |
| 🚫 BANのみ | BANだけを行い、PICKはせずに結果へ。試合ではBANされた武器以外から各自が選ぶ |

- **相手ピック**: ピック順で対応する選手同士（Alpha[1] ↔ Bravo[1] など）がペアになり、互いの武器を選び合います。担当の選手だけが操作でき、画面には対象プレイヤー名が表示されます。同時ピックとも併用できます。
- **BANのみ**: 代表者BAN・個人BANのどちらも選べます。個人BANはピック順の上位の人が担当し、人数が少ないときは1人が複数枠を担当します（ジャンルBANは代表者BANのみ）。BANを1つ以上設定する必要があります。お題カード・トレード・武器ロックアウトは使えません。結果画面には使用可能な武器の数が表示されます。

#### 武器の絞り込み（ホスト設定）
- 「🚫 武器の絞り込み」から、武器種 / サブウェポン / スペシャルウェポンのチェックリストを開けます。
- チェックした要素をいずれか1つでも持つ武器は、そのドラフトのBAN/PICK候補から除外されます（例: チャージャーをチェック→チャージャーが選べない／スペシャルをチェック→そのスペシャルを持つ武器が消える）。
- 「標準武器のみ」と併用でき、候補に残る武器数も表示されます。

#### レプリカの非表示（既定ON）
- ヒーローシューター レプリカ・オクタシューター レプリカ・PETシューター レプリカ・オーダー系（オーダーシューター レプリカなど）の14種は、元ブキと性能が同じで見た目だけ違うため、初期状態ではBAN/PICK候補に出しません。
- 設定の「レプリカを非表示」をOFFにすると、レプリカも選べるようになります（ソロ・マルチ・マイプリセットに対応）。

#### タイマー
- ソロ・マルチとも制限時間を設定できます（5〜100秒・既定30秒）。
- 時間切れ時は「確定済み → 仮選択中 → ランダム」の優先順で自動送信します。メンバードラフトや武器ピックのターンにも適用されます。

### チーム分け

#### ランダム振り分けとタグ（マルチ）
- ロビーの「🎲 ランダム振り分け」はプレビューを表示し、「もう一回」で引き直し、「この分け方で確定」で反映します。各チームは設定人数まで入り、あふれた人は未割り当てに残ります。
- ホストはメンバーにタグを付けられます（最大4種類・1人1つ・名前は自由入力）。タグは「分ける」か「まとめる」を選べます。
  - 分ける: 同じタグの人を両チームに均等に分けます（例: 長射程2人→1人ずつ、つよい4人→2人ずつ）。
  - まとめる: 同じタグの人を同じチームに入れます。
- タグの無い人は残りの枠にランダムに入ります。人数があふれるときは、タグの無い人から未割り当てになります。タグはホストにだけ表示されます。

#### メンバードラフト（キャプテン選抜・マルチ専用）
武器ドラフトの前に、キャプテン選抜方式でチーム分けを行うモードです。
- ホストが各チームのキャプテンを1名ずつ指定し（残りは未割り当て＝プール）、2人のキャプテンが交互にプールから1人ずつ指名してチームを埋めます。先攻チームが先に指名します。
- 2v2以上で人数が揃っているときに開始でき、制限時間ONならターンの時間切れでランダム自動指名されます。
- 「タイミング」を2通りから選べます。
  - チーム分け → ドラフト: 選抜が終わるとそのまま武器ドラフトへ進み、指名した順番がそのままピック順になります。
  - 全員が武器ピック → チーム分け: 先に全員（キャプテン含む）がランダム順で1人ずつ武器を選び（同じ武器は選べません）、その後にキャプテンがチーム分けします。各自が選んだ武器を持ったまま結果へ進みます（BANなし）。

### 連戦とステージ

#### 連戦モード（シリーズ）
1つのルームで複数試合を連続して行うオプションです。BO3（先取2）/ BO5（先取3）/ BO7（先取4）/ BO9（先取5）から選べます。
- 結果画面でホストが勝者を入力すると次の試合へ進み、先取数に達するとシリーズ終了。
- 各試合の編成を一覧できる戦績ボードと、全試合をまとめたシリーズ画像を出力できます。
- 連戦中だけの追加オプションとして、武器ロックアウト（一度ピックした武器を以降の試合で使えない）や、負けチームが次戦のガチルールを選ぶ設定があります。

#### ステージ方式
「ステージ方式」から選び、通常以外は候補プールを設定します。候補は最大試合数を通して不足しない数が必要です。初期状態では全ステージが候補です。

| 方式 | 流れ |
|---|---|
| 通常 | 1試合では指定またはランダム。連戦では各試合ランダム |
| おまかせロスト | 候補から毎試合ランダムに選び、シリーズ中に使用したステージを除外 |
| カウンターピック | 初戦は候補からランダム。以降は直前の敗者の代表者が未使用のステージを選択 |
| BAN / PICK | 両チームが各1 BANし、先攻から交互にステージをPICK。最終戦は残りから抽選 |

- BAN / PICK は、このツール独自の方式です。BO3では各1 PICK、BO5では各2 PICK、BO7では各3 PICK、BO9では各4 PICKとなり、最後の試合は抽選します。連戦OFFの1試合では各1 BAN後に先攻がPICKします。
- 必要な候補数: BAN / PICK は最大試合数＋2（1試合は3、BO3は5、BO5は7、BO7は9、BO9は11）。ロスト・カウンターは最大試合数以上。
- ステージは画像付きの項目を1回押すと仮選択、同じ項目をもう一度押すと確定します。マルチでは各チームの代表者、ソロでは操作者が選びます。ステージ選択中は制限時間なし。
- 「全員が武器ピック → チーム分け」では通常以外の方式を使えません。

### 遊び要素

#### お題カード / 縛りルーレット
- 「🎯 お題カード（縛りルーレット）」をONにすると、ドラフト開始時にお題を1枚ランダム抽選します（両チーム共通）。抽選はルーレット演出で表示されます。
- お題は全32種（例:「全員ちがう武器種」「全員サブがボム系」「チャージャーを入れる」「武器種は2種類まで」など）。
- 非強制でピックは制限されません。結果画面・結果画像に各チームの達成（○ / ×）が表示される、パーティ向けの遊び要素です。

#### ドラフト後トレード
結果画面で、自チームの武器1枚と相手チームの武器1枚の交換を提案できるオプションです。相手チームの代表者が承認すると成立し、成立回数に制限はありません（ソロではその場で入れ替え）。

#### 確定演出 / 武器読み上げ
ドラフト画面右上のトグルで、BAN/PICK確定時の効果音（🔊）と、確定した武器名の読み上げ（🗣️）を切り替えられます。どちらも既定OFF・端末ごとに保存されます。音はブラウザ内で生成しており、外部ファイルの読み込みや送信はありません。

### 部屋づくり・設定

#### 部屋作成のプリセット
「部屋を作る」から、自由に設定するか、説明付きのプリセットを選べます。各プリセットは4対4で始まり、作成後にロビーで人数や各種設定を変更できます。

| プリセット | 初期設定 |
|---|---|
| 基本の武器ドラフト | 武器BAN各4・代表者BAN・個人ピック・スネーク順 |
| 代表者どうしで気軽に | 武器BAN各2・代表者BAN・代表者ピック |
| 同時ピック | 武器BAN各2・代表者BAN・個人ピック・同時ピック |
| お題付きガチャ | 武器BANなし・ガチャ・お題カードON |
| BO3 ステージ BAN / PICK | 武器BAN各2・代表者ピック・BO3・ステージBAN/PICK ON |

#### マイプリセット
- ロビー下部で現在の設定に名前を付け、このブラウザに最大50件保存できます。「部屋を作る」→「プリセットから選ぶ」で保存した設定から部屋を作り、変更して上書き保存できます。
- 一覧では名前変更・削除、全件のJSONファイルへの書き出し・読み込みができます（読み込みは既存を消さず追加）。
- 保存対象は部屋のルール設定とチーム名です（部屋番号・参加者・ピック順の担当者・試合結果は含まない）。保存は端末とブラウザごとで自動同期されないため、移行やバックアップには書き出したファイルを使ってください。

#### その他の設定
- ルール選択（ナワバリバトル / ガチエリア / ガチヤグラ / ガチホコ / ガチアサリ）。「ランダム」はガチ4ルールから抽選します（ナワバリバトルは明示選択時のみ）。
- 全11カテゴリの武器に対応（シューター / ローラー / チャージャー / スロッシャー / スピナー / マニューバー / シェルター / ブラスター / フデ / ワイパー / ストリンガー）
- 標準武器のみモード／チーム名カスタマイズ／人数設定（1v1〜4v4）／先攻チーム設定（初期値ランダム / アルファ / ブラボー）

### 共有・配信・端末まわり

#### 結果画像の保存
- 結果画面の「🖼️ 結果画像を保存」で、ルール・ステージ・両チームのBAN/PICKをまとめた1枚のPNGを保存できます。連戦時は全試合をまとめたシリーズ画像も出せます。
- 画像生成は端末内で完結し（外部送信なし）、個人ピック時はプレイヤー名も併記されます。

#### 配信時の部屋番号の非表示
- 部屋番号は初期状態で伏せられ、モード選択・参加・ロビー・ドラフト画面のボタンで切り替えられます。再読み込みすると非表示に戻ります。
- 非表示中もID・URLのコピーは使えます。アドレス欄や共有URLには部屋番号が含まれるため、配信に映さず参加者だけに共有してください。表示を隠す機能であり、入室制限ではありません。

#### その他
- URLにルームIDが入るので共有が簡単
- スマートフォンで「ホーム画面に追加」すると、アイコン付きでアプリのように起動できます（PWA）
- 狭幅のスマホ画面でも崩れにくいモバイル対応

## ドラフトの流れ（モード別）

<details>
<summary><b>代表者BAN</b></summary>

- ホスト（アルファ代表）とブラボー代表が、同時にBANしたい武器を選んで送信します。
- 相手には「送信済み」とだけ表示され、内容は伏せられます。
- 両方届いた時点で自動公開・確定されます。代表者以外はBAN操作できません。
</details>

<details>
<summary><b>個人BAN</b></summary>

- ピック順上位の各プレイヤーが、それぞれ担当の武器を選んで送信します。
- 味方が送信したBANはBAN中もグリッド・パネルに共有表示され、チーム内での重複を避けられます。相手チームのBANは全員分そろうまで伏せられます。
- 全員分の送信が揃った時点で自動公開・確定されます。
</details>

<details>
<summary><b>個人ピック</b></summary>

- 自分のターンになったら武器を選択して送信します。
- ターン外のプレイヤーは他チームの選択を待ちます。
- 全員のピックが終わるとリザルト画面へ進みます。
</details>

<details>
<summary><b>同時ピック（マルチ専用）</b></summary>

- 各ラウンドで「アルファのN番目」と「ブラボーのN番目」のペア2人だけが担当し、同時に武器を選びます。同じ武器をもう一度タップすると確定と同時に送信されます（送信ボタンはありません）。
- 担当外のプレイヤーはそのラウンド中は操作できず、ペアの選択を待ちます。
- 両方そろうとホスト側に公開画面が表示され、「次へ」で確定すると全員が次ラウンドへ進みます。
- 被りあり仕様（同じ武器を両チームがピックしてもそのまま確定）です。
</details>

<details>
<summary><b>相手ピック</b></summary>

- ピック順で対応する選手同士がペアになります（例: アルファ1人目 ↔ ブラボー1人目）。
- 自分のターンでは、ペアになっている相手プレイヤーが使う武器を選びます（画面に対象プレイヤー名が表示されます）。
- リザルトには各プレイヤーが実際に使う武器（＝相手に選ばれた武器）が名前付きで表示されます。
</details>

<details>
<summary><b>ドラフト中にロビーへ戻る（ホスト専用）</b></summary>

- ドラフト画面のホスト側に「← ロビーに戻る」ボタンが表示されます。
- 押すと確認のうえドラフトをリセットし、ロビーへ戻ります。メンバー情報は保持されるので、設定を変えて即座に再ドラフトできます。
- 参加者側はホストがロビーへ戻ったことを自動検知し、ロビー待機画面へ遷移します。
</details>

## セキュリティと統計

### セキュリティ
- **Firebase 匿名認証** — サイトを開くと自動でログイン（入力不要）。未認証からの読み書きをブロック
- **Database Rules** — 認証済みユーザーのみ・6文字英数字のルームIDのみアクセス可能（想定形は [`database.rules.json`](./database.rules.json)）
- **ルーム自動削除** — 24時間以上経過したルームをGitHub Actionsで毎週月曜の深夜0時（JST）に自動削除（手動実行も可）
- **XSS対策** — プレイヤー名・チーム名など Firebase 経由の文字列は表示時にすべてHTMLエスケープ

### 統計（匿名集計）
- マルチプレイのドラフト完了時に、**武器別のPICK/BAN回数とドラフト総数のみ**を匿名で集計します。ルームID・プレイヤー名・チーム名・日時は送信しません。
- 集計結果はモード選択画面の**「📊 武器統計」**から誰でも閲覧できます（PICK／BAN／ジャンルBANのランキング）。詳細とセットアップ手順は [docs/stats-setup.md](./docs/stats-setup.md)。
- 「この端末」に切り替えると、このブラウザで参加したドラフト（ソロ含む・両チーム分）を別に集計できます。端末内の保存なのでFirebaseの容量は増えず、別端末への同期はされません。ブラウザのデータ削除で消えることがあります。
