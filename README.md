# 🦑 Splatoon Draft Tool

スプラトゥーン向けのオンライン武器ドラフトツールです。  
ホストと参加者に分かれてリアルタイムでBANとPICKを行えます。

🔗 **[ツールを開く](https://shitake-zense.github.io/splatoon-draft/)**

---

## 機能

### 対戦形式
- **マルチプレイ** — ルームIDを共有してホスト/参加者に分かれてドラフト
- **ソロ** — 1人で両チーム分を操作してドラフト確認

### BAN フェーズ
- 両チームが**同時に**BAN武器を選択・送信
- 相手の選択内容は送信が完了するまで伏せられる
- 両チームの送信が揃った時点で自動的に公開・確定

### PICK フェーズ（5種類から選択）

| モード | 説明 |
|---|---|
| 交互 | 先攻→後攻→先攻… と1枚ずつ交互 |
| スネーク | 先1→後2→先2→後1（4v4の基本形） |
| バランス | 先1-2-1 / 後1-2-1 |
| 前重ね | 先2-1-1 / 後1-2-1 |
| **同時ピック** | 両チームが同時に選択し4回一斉公開。被りあり |

### 同時ピックのフロー
1. 両チームが武器を選択して送信（相手には「選択済み ✓」と表示）
2. 両方の送信が確認されたらホスト側に公開オーバーレイが表示される
3. ホストが「次へ」を押すと参加者画面も自動で次のラウンドへ進む
4. これを4ラウンド繰り返す（**被りOK仕様**）

### その他
- ルール・ステージのランダム選択
- 標準武器のみモード
- チーム名のカスタマイズ
- BAN数・ピック数の設定（1〜10）

## 使い方

### マルチプレイ
1. ホストが「ホストとして部屋を作る」を選択
2. 設定（チーム名・BAN数・ピック数・ピック順など）を入力して「部屋を作る」
3. 表示されたルームIDを参加者に共有
4. 参加者が「部屋に参加する」からルームIDを入力して入室
5. ホストが「ドラフト開始」を押してスタート

### BAN の流れ（マルチ）
- ホストとブラボー（参加者）が**同時に**BANしたい武器を選んで送信
- 両方届いた時点で自動公開

### 同時ピックの流れ（マルチ）
- 各ラウンドで武器を選び「PICKを送信する」をタップ
- 相手が送信するまで待機（「送信済み ✓」と表示される）
- 両方揃ったらホスト側に公開画面が出る
- ホストが「次へ」で確定 → 参加者画面も自動で次へ進む

## 技術構成

- **フロントエンド**: HTML / CSS / Vanilla JS（単一ファイル構成）
- **リアルタイム同期**: Firebase Realtime Database
- **ホスティング**: GitHub Pages
- **武器データ**: スプラトゥーン3 全武器対応
