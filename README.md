# 🦑 Splatoon Draft Tool

スプラトゥーン3向けのオンライン武器ドラフトツールです。
ホストと参加者に分かれてリアルタイムでBANとPICKを行えます。

🔗 **[ツールを開く](https://shitake-zense.github.io/splatoon-draft/)**

---

## 機能

### 対戦形式
- **マルチプレイ** — ルームIDを共有してホスト/参加者に分かれてドラフト（最大8人）
- **ソロ** — 1人で両チーム分を操作してドラフト確認

### BAN フェーズ（2種類）

| モード | 説明 |
|---|---|
| 代表者BAN | 両チームが同時にBAN武器を選択・送信。相手の選択内容は送信が完了するまで伏せられる |
| 個人BAN | 各プレイヤーが自分でBAN武器を選択・送信（ピック順上位bc人が担当） |

### PICK フェーズ（7種類から選択）

| モード | 説明 | 対応 |
|---|---|---|
| 交互 | 先攻→後攻→先攻… と1枚ずつ交互 | ソロ・マルチ |
| スネーク | 先1→後2→後2→先1→先1→先1（デフォルト） | ソロ・マルチ |
| クラシックスネーク | 先1→後3→先3→後1 | ソロ・マルチ |
| ミドルスネーク | 先1→後2→後2→後2→先1 | ソロ・マルチ |
| バランス | 先1-2-1 / 後1-2-1 | ソロ・マルチ |
| 前重ね | 先2-1-1 / 後1-2-1 | ソロ・マルチ |
| 同時ピック | 両チームが同時に選択し4回一斉公開。被りあり | **マルチ専用** |

### ピックモード（2種類）

| モード | 説明 |
|---|---|
| 👥 個人ピック | 各プレイヤーが自分のターンに自分で武器を選択 |
| 🤝 代表者ピック | チームの代表者（ホスト/参加者）がチーム全員分を選択 |

### タイマー機能
- ソロ・マルチともに制限時間を設定可能（15秒 / 20秒 / 30秒）
- 時間切れ時にBAN・PICKを自動送信（仮選択中の武器 → ランダムの優先順）

### その他
- ルール・ステージのランダム選択（ガチエリア / ガチヤグラ / ガチホコ / ガチアサリ）
- 標準武器のみモード
- チーム名カスタマイズ
- 人数設定（1v1〜4v4）
- BAN数設定（なし〜各4BAN）
- 先攻チーム設定（アルファ / ブラボー / ランダム）
- URLにルームIDが入るので共有が簡単

## 使い方

### マルチプレイ
1. ホストが「ホストとして部屋を作る」を選択
2. チーム名・BAN数・ピック数・ピックモード・BANモード・制限時間などを設定して「部屋を作る」
3. 表示されたルームIDを参加者に共有
4. 参加者が「部屋に参加する」からルームIDを入力して入室
5. ホストがチーム編成を確認し「ドラフト開始」を押してスタート

> **参加者の退出**: チーム分けの各メンバー横に表示される「×」ボタンをホストが押すと、その参加者をロビーから退出させてモード選択画面に戻すことができます。

> **個人ピックモードのとき**: アルファ・ブラボー両チームとも設定人数が揃わないと「ドラフト開始」ボタンが有効になりません。ロビー画面に現在の参加人数が表示されます。

### 代表者BANの流れ
- ホスト（アルファ代表）とブラボー代表の参加者が同時にBANしたい武器を選んで送信
- 相手には「送信済み」とだけ表示され内容は伏せられる
- 両方届いた時点で自動公開・確定
- 代表者以外のメンバーはBAN操作不可（グリッドが無効化される）

### 個人BANの流れ
- ピック順上位の各プレイヤーがそれぞれ担当武器を選んで送信
- 全員分の送信が揃った時点で自動公開・確定

### 同時ピックの流れ（マルチ専用）
- 各ラウンドで武器を選び「PICKを送信する」をタップ
- 両方揃ったらホスト側に公開画面が表示される
- ホストが「次へ」で確定し参加者画面も自動で次へ進む
- 被りあり仕様（同じ武器を両チームがピックしてもそのまま確定）

### 個人ピックの流れ
- 自分のターンになったら武器を選択して送信
- ターン外のプレイヤーは他チームの選択を待機
- 全員のピックが終わるとリザルト画面へ

### ドラフト中にロビーへ戻る（ホスト専用）
- ドラフト画面のホスト側に「← ロビーに戻る」ボタンが表示されます
- 押下すると確認ダイアログが表示され、承認するとドラフトをリセットしてロビー画面へ戻ります
- メンバー情報はそのまま保持されるため、設定を変更して即座に再ドラフトが可能です
- 参加者側はホストがロビーへ戻ったことを自動検知し、ロビー待機画面に遷移します

## セキュリティ

- **Firebase 匿名認証** — サイトを開くと自動でログイン（入力不要）。未認証からの読み書きをブロック
- **Database Rules** — 認証済みユーザーのみ・6文字英数字のルームIDのみアクセス可能
- **ルーム自動削除** — 24時間以上経過したルームをGitHub Actionsで毎日深夜0時（JST）に自動削除

---

## 技術構成

- **フロントエンド**: HTML / CSS / Vanilla JS（単一ファイル構成）
- **リアルタイム同期**: Firebase Realtime Database
- **認証**: Firebase Authentication（匿名ログイン）
- **ホスティング**: GitHub Pages
- **自動削除**: GitHub Actions（毎日実行）
