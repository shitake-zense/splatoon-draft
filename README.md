# 🦑 Splatoon Draft Tool

スプラトゥーン3向けのオンライン武器ドラフトツールです。
ホストと参加者に分かれてリアルタイムでBANとPICKを行えます。

🔗 **[ツールを開く](https://shitake-zense.github.io/splatoon-draft/)**

---

## 機能

### 対戦形式
- **マルチプレイ** — ルームIDを共有してホスト/参加者に分かれてドラフト
- **ソロ** — 1人で両チーム分を操作してドラフト確認

### BAN フェーズ（同時方式）
- 両チームが同時にBAN武器を選択・送信
- 相手の選択内容は送信が完了するまで伏せられる
- 両チームの送信が揃った時点で自動的に公開・確定

### PICK フェーズ（5種類から選択）

| モード | 説明 |
|---|---|
| 交互 | 先攻→後攻→先攻… と1枚ずつ交互 |
| スネーク | 先1→後2→先2→後1（4v4の基本形） |
| バランス | 先1-2-1 / 後1-2-1 |
| 前重ね | 先2-1-1 / 後1-2-1 |
| 同時ピック | 両チームが同時に選択し4回一斉公開。被りあり |

### その他
- ルール・ステージのランダム選択
- 標準武器のみモード
- チーム名カスタマイズ
- BAN数・ピック数の設定（1〜10）
- URLにルームIDが入るので共有が簡単

## 使い方

### マルチプレイ
1. ホストが「ホストとして部屋を作る」を選択
2. チーム名・BAN数・ピック数・ピック順などを設定して「部屋を作る」
3. 表示されたルームIDを参加者に共有
4. 参加者が「部屋に参加する」からルームIDを入力して入室
5. ホストが「ドラフト開始」を押してスタート

### BAN の流れ
- ホストとブラボー（参加者）が同時にBANしたい武器を選んで送信
- 相手には「送信済み」とだけ表示され内容は伏せられる
- 両方届いた時点で自動公開・確定

### 同時ピックの流れ
- 各ラウンドで武器を選び「PICKを送信する」をタップ
- 両方揃ったらホスト側に公開画面が表示される
- ホストが「次へ」で確定し参加者画面も自動で次へ進む
- 被りあり仕様（同じ武器を両チームがピックしてもそのまま確定）

## セキュリティ

- **Firebase 匿名認証** — サイトを開くと自動でログイン（入力不要）。未認証からの読み書きをブロック
- **Database Rules** — 認証済みユーザーのみ・6文字英数字のルームIDのみアクセス可能
- **ルーム自動削除** — 24時間以上経過したルームをGitHub Actionsで毎日深夜0時に自動削除

---

## 技術構成

- **フロントエンド**: HTML / CSS / Vanilla JS（単一ファイル構成）
- **リアルタイム同期**: Firebase Realtime Database
- **認証**: Firebase Authentication（匿名ログイン）
- **ホスティング**: GitHub Pages
- **自動削除**: GitHub Actions（毎日実行）
