# 🦑 Splatoon Draft Tool

スプラトゥーン3向けのオンライン武器ドラフトツールです。
ホストと参加者に分かれてリアルタイムでBANとPICKを行えます。

🔗 **[ツールを開く](https://shitake-zense.github.io/splatoon-draft/)**

> 設計の意図やトレードオフ、既知の課題、今後の展望については [DEVELOPMENT.md](./DEVELOPMENT.md) を参照してください。
> 新機能の開発計画・進捗・再開手順は [ROADMAP.md](./ROADMAP.md) にまとめています。

---

## 機能

### 対戦形式
- **マルチプレイ** — ルームIDを共有してホスト/参加者に分かれてドラフト（最大8人）
- **ソロ** — 1人で両チーム分を操作してドラフト確認

### BAN フェーズ（2種類）

| モード | 説明 |
|---|---|
| 代表者BAN | 両チームが同時にBAN武器を選択・送信。相手の選択内容は送信が完了するまで伏せられる |
| 個人BAN | 各プレイヤーが自分でBAN武器を選択・送信（ピック順上位bc人が担当） |

### PICK フェーズ（7種類から選択）

| モード | 説明 | 対応 |
|---|---|---|
| 交互 | 先攻→後攻→先攻… と1枚ずつ交互 | ソロ・マルチ |
| スネーク | 先1→後2→後2→先1→先1→先1（デフォルト） | ソロ・マルチ |
| クラシックスネーク | 先1→後3→先3→後1 | ソロ・マルチ |
| ミドルスネーク | 先1→後2→後2→後2→先1 | ソロ・マルチ |
| バランス | 先1-2-1 / 後1-2-1 | ソロ・マルチ |
| 前重ね | 先2-1-1 / 後1-2-1 | ソロ・マルチ |
| 同時ピック | 両チームが同時に選択し4回一斉公開。被りあり | **マルチ専用** |

### ピックモード（3種類）

| モード | 説明 |
|---|---|
| 👥 個人ピック | 各プレイヤーが自分のターンに自分で武器を選択 |
| 🤝 代表者ピック | チームの代表者（ホスト/参加者）がチーム全員分を選択 |
| 🆚 相手ピック | 各プレイヤーが**対になる相手プレイヤーの使用武器**を選ぶ（相手が使う武器を自分が決める）。ピック順で対応する者同士がペアになり、選択した武器は相手のロードアウトになります |

> 相手ピックは個人粒度です。ピック順で各チームの対応する選手（Alpha[1]↔Bravo[1] など）がペアになり、お互いの武器を選び合います。担当の選手だけが操作でき、画面には「誰の武器を選んでいるか（対象プレイヤー名）」が表示されます。**同時ピックとの併用も可能**です（ペアが同時に互いの武器を選択）。

### 武器の絞り込み（ホスト設定）

- ルール設定の「🚫 武器の絞り込み」から、**武器種 / サブウェポン / スペシャルウェポン** のチェックリストを開けます。
- チェックした要素を**いずれか1つでも持つ武器**は、そのドラフトのBAN/PICK候補から除外されます（例: チャージャーをチェック→チャージャーが選べない／スペシャルをチェック→そのスペシャルを持つ武器が全消去）。
- 「標準武器のみ」と併用でき、ピック可能な残り武器数も表示されます。

### お題カード / 縛りルーレット

- ルール設定（マルチ・ソロ両方）の「🎯 お題カード（縛りルーレット）」をONにすると、ドラフト開始時に**お題を1枚ランダム抽選**します（両チーム共通）。
- 抽選はルーレット演出で表示。お題は**全32種**から1枚（武器種・サブ・スペシャル・人数など色々な角度）。例:「全員ちがう武器種」「武器種は2種類まで」「全員サブがボム系」「ボム系サブ禁止」「全員おなじスペシャル」「シューターは1人まで」「チャージャーを入れる」「ローラー禁止」など。
- **非強制**（ピックは制限されません）。結果画面・結果画像に各チームの達成（○ / ×）が表示されます。エンジョイ・パーティ向けの遊び要素です。

### メンバードラフト（キャプテン選抜・マルチ専用）
- ルール設定の「🧑‍🤝‍🧑 メンバードラフト」をONにすると、武器ドラフトの前に**チーム分けをキャプテン選抜方式**で行えます。
- ホストが各チームの**キャプテンを1名ずつ**指定（α/βに1名ずつ割り当て、残りは未割り当て＝プール）。両チーム代表者が揃い、かつ**人数が足りている（2v2以上・合計が2×人数以上）**ときのみ「メンバードラフト開始」が押せます。
- 開始すると、2人のキャプテンが**交互にプールから1人ずつ指名**してチームを埋めます。先攻設定のチームが先に指名します。
- 制限時間ONのときは**ターンに時間切れがあり、時間切れでプールからランダム自動指名**されます。
- 両チームが規定人数に達したら選抜完了 → そのまま通常の武器ドラフトへ進みます。

### タイマー機能
- ソロ・マルチともに制限時間を設定可能（5〜100秒の範囲で入力・デフォルト30秒）
- 時間切れ時にBAN・PICKを自動送信（**確定済み → 仮選択中の武器 → ランダム**の優先順。同時ピックで2タップ確定した武器も尊重されます）
- メンバードラフトのターンにも適用され、時間切れでプールからランダム自動指名します

### 結果画像の保存
- リザルト画面の「🖼️ 結果画像を保存」で、ルール・ステージ・両チームのBAN/PICKをまとめた1枚のPNG画像を生成・ダウンロードできます
- 画像生成は端末内で完結（外部サービス送信なし）。個人ピック時はプレイヤー名も併記されます

### ホーム画面に追加（PWA）
- スマートフォンで「ホーム画面に追加」するとアイコン付きでアプリのように起動できます

### その他
- ルール選択（ナワバリバトル / ガチエリア / ガチヤグラ / ガチホコ / ガチアサリ）。「ランダム」はガチ4ルールから抽選（ナワバリバトルは明示選択時のみ）
- ステージのランダム選択
- 全武器カテゴリに対応（シューター / ローラー / チャージャー / スロッシャー / スピナー / マニューバー / シェルター / ブラスター / フデ / ワイパー / ストリンガー）
- 標準武器のみモード
- チーム名カスタマイズ
- 人数設定（1v1〜4v4）
- BAN数設定（なし〜各8BAN・デフォルト各4BAN）
- 先攻チーム設定（アルファ / ブラボー / ランダム）
- URLにルームIDが入るので共有が簡単
- スマートフォンの狭幅画面でもレイアウトが崩れにくいモバイル対応

## 使い方

### マルチプレイ
1. ホストが「ホストとして部屋を作る」を選択
2. チーム名・BAN数・ピック数・ピックモード・BANモード・制限時間などを設定して「部屋を作る」
3. 表示されたルームIDを参加者に共有
4. 参加者が「部屋に参加する」からルームIDを入力して入室
5. ホストがチーム編成を確認し「ドラフト開始」を押してスタート

> **参加者の退出**: チーム分けの各メンバー横に表示される「×」ボタンをホストが押すと、その参加者をロビーから退出させてモード選択画面に戻すことができます。

> **同じ端末での再参加**: チーム割り当て済みの参加者が誤ってページを閉じる・再読み込みした場合でも、同じ端末・同じブラウザで再入室すれば**元のチーム枠（ピック順割り当て）を引き継いで復帰**します。再参加時に名前を変更することも可能です。

> **個人ピックモードのとき**: アルファ・ブラボー両チームとも設定人数が揃わないと「ドラフト開始」ボタンが有効になりません。ロビー画面に現在の参加人数が表示されます。

### 代表者BANの流れ
- ホスト（アルファ代表）とブラボー代表の参加者が同時にBANしたい武器を選んで送信
- 相手には「送信済み」とだけ表示され内容は伏せられる
- 両方届いた時点で自動公開・確定
- 代表者以外のメンバーはBAN操作不可（グリッドが無効化される）

### 個人BANの流れ
- ピック順上位の各プレイヤーがそれぞれ担当武器を選んで送信
- **味方が送信したBAN武器はBANフェーズ中に見えます**（チーム内でBANの重複を避けやすくするため）。相手チームのBANは送信が揃うまで伏せられます
- 全員分の送信が揃った時点で自動公開・確定

### 同時ピックの流れ（マルチ専用）
- 各ラウンドで「アルファのN番目」と「ブラボーのN番目」のペア2人だけが担当し、同時に武器を選んで「PICKを送信する」をタップ
- 担当外のプレイヤーはそのラウンド中は操作できず、ペアの選択を待機
- 両方揃ったらホスト側に公開画面が表示され、ホストが「次へ」で確定すると全員の画面が次ラウンドへ進む
- 被りあり仕様（同じ武器を両チームがピックしてもそのまま確定）

### 個人ピックの流れ
- 自分のターンになったら武器を選択して送信
- ターン外のプレイヤーは他チームの選択を待機
- 全員のピックが終わるとリザルト画面へ

### 相手ピックの流れ
- ピック順で対応する選手同士がペアになります（例: アルファ1人目 ↔ ブラボー1人目）
- 自分のターンでは、**ペアになっている相手プレイヤーが使う武器**を選びます（画面に対象プレイヤー名が表示されます）
- 担当のプレイヤーだけが操作でき、他のメンバーは待機します
- リザルトには各プレイヤーが「実際に使う武器」（＝相手に選ばれた武器）が名前付きで表示されます
- 個人ピックモードと同様、両チームの人数が揃うまで「ドラフト開始」は有効になりません

### ドラフト中にロビーへ戻る（ホスト専用）
- ドラフト画面のホスト側に「← ロビーに戻る」ボタンが表示されます
- 押下すると確認ダイアログが表示され、承認するとドラフトをリセットしてロビー画面へ戻ります
- メンバー情報はそのまま保持されるため、設定を変更して即座に再ドラフトが可能です
- 参加者側はホストがロビーへ戻ったことを自動検知し、ロビー待機画面に遷移します

## セキュリティ

- **Firebase 匿名認証** — サイトを開くと自動でログイン（入力不要）。未認証からの読み書きをブロック
- **Database Rules** — 認証済みユーザーのみ・6文字英数字のルームIDのみアクセス可能
- **ルーム自動削除** — 24時間以上経過したルームをGitHub Actionsで毎日深夜0時（JST）に自動削除

---

## 技術構成

- **フロントエンド**: HTML / CSS / Vanilla JS（単一ファイル構成）
- **リアルタイム同期**: Firebase Realtime Database
- **認証**: Firebase Authentication（匿名ログイン）
- **ホスティング**: GitHub Pages
- **自動削除**: GitHub Actions（毎日実行）
