# 🦑 Splatoon Draft Tool

スプラトゥーン3向けのオンライン武器ドラフトツールです。ホストと参加者に分かれて、リアルタイムでBANとPICKを行えます。1人で両チームを操作して試せるソロモードもあります。

🔗 **[ツールを開く](https://shitake-zense.github.io/splatoon-draft/)**

> 設計の意図やトレードオフ、既知の課題、今後の展望は [DEVELOPMENT.md](./DEVELOPMENT.md) を参照してください。
> 開発計画・進捗・再開手順は [ROADMAP.md](./ROADMAP.md) にまとめています。

## 機能

### 対戦形式
- マルチプレイ — ルームIDを共有し、ホスト/参加者に分かれてドラフト（最大8人）
- ソロ — 1人で両チーム分を操作してドラフトを確認

### BAN フェーズ
試合で使えない武器を事前に封じるフェーズです。BAN数は「なし〜各8」で設定できます（既定は各4）。

| モード | 説明 |
|---|---|
| 代表者BAN | 両チームが同時にBANを選んで送信。相手の選択は両者そろうまで伏せられ、揃った時点で一斉公開・確定されます |
| 個人BAN | ピック順上位のプレイヤーがそれぞれ担当のBANを送信。味方のBANはBAN中もチーム内で共有表示され、重複を避けられます（相手のBANは伏せたまま） |

武器単位とは別枠で、武器種 / サブ / スペシャル単位の「ジャンルBAN」も設定できます（代表者BAN相当のとき）。例えば「サブ＝2」にすると、サブを2種類まるごと禁止＝そのサブを持つ武器をすべて候補から外せます。

### PICK フェーズ（ピック順・7種類）
チームが武器を選ぶ順番を選べます。

| ピック順 | 並び | 対応 |
|---|---|---|
| 交互 | 先攻→後攻→先攻… と1枚ずつ交互 | ソロ・マルチ |
| スネーク | 先1→後2→後2→先1→先1→先1（既定） | ソロ・マルチ |
| クラシックスネーク | 先1→後3→先3→後1 | ソロ・マルチ |
| ミドルスネーク | 先1→後2→後2→後2→先1 | ソロ・マルチ |
| バランス | 先1-2-1 / 後1-2-1 | ソロ・マルチ |
| 前重ね | 先2-1-1 / 後1-2-1 | ソロ・マルチ |
| 同時ピック | 両チームが同時に選択し4回一斉公開。被りあり | マルチ専用 |

### ピックモード（4種類）
誰が、どの武器を選ぶかの方式です。

| モード | 説明 |
|---|---|
| 👥 個人ピック | 各プレイヤーが自分のターンに自分の武器を選択 |
| 🤝 代表者ピック | チーム代表者がチーム全員分をまとめて選択 |
| 🆚 相手ピック | 対になる相手プレイヤーの使用武器を選ぶ（相手が使う武器を自分が決める） |
| 🎲 ガチャ（運命ピック） | BAN後に人数分の武器がランダム配布される。チームごとに数回まで引き直し（リロール）でき、両チーム確定で結果へ |

> 相手ピックは、ピック順で対応する選手同士（Alpha[1] ↔ Bravo[1] など）がペアになり、互いの武器を選び合う個人粒度のモードです。担当の選手だけが操作でき、画面には「誰の武器を選んでいるか（対象プレイヤー名）」が表示されます。同時ピックとの併用もできます。

### 武器の絞り込み（ホスト設定）
- 「🚫 武器の絞り込み」から、武器種 / サブウェポン / スペシャルウェポンのチェックリストを開けます。
- チェックした要素をいずれか1つでも持つ武器は、そのドラフトのBAN/PICK候補から除外されます（例: チャージャーをチェック→チャージャーが選べない／スペシャルをチェック→そのスペシャルを持つ武器が消える）。
- 「標準武器のみ」と併用でき、候補に残る武器数も表示されます。

### お題カード / 縛りルーレット
- 「🎯 お題カード（縛りルーレット）」をONにすると、ドラフト開始時にお題を1枚ランダム抽選します（両チーム共通）。抽選はルーレット演出で表示されます。
- お題は全32種。武器種・サブ・スペシャル・人数などさまざまな角度のものがあります（例:「全員ちがう武器種」「全員サブがボム系」「チャージャーを入れる」「武器種は2種類まで」など）。
- 非強制でピックは制限されません。結果画面・結果画像に各チームの達成（○ / ×）が表示される、パーティ向けの遊び要素です。

### メンバードラフト（キャプテン選抜・マルチ専用）
武器ドラフトの前に、キャプテン選抜方式でチーム分けを行うモードです。
- ホストが各チームのキャプテンを1名ずつ指定し（残りは未割り当て＝プール）、2人のキャプテンが交互にプールから1人ずつ指名してチームを埋めます。先攻チームが先に指名します。
- 2v2以上で人数が揃っているときに開始でき、制限時間ONならターンの時間切れでランダム自動指名されます。
- 「タイミング」を2通りから選べます。
  - チーム分け → ドラフト: 選抜が終わるとそのまま武器ドラフトへ進み、指名した順番がそのままピック順になります。
  - 全員が武器ピック → チーム分け: 先に全員（キャプテン含む）がランダム順で1人ずつ武器を選び（同じ武器は選べません）、その後にキャプテンがチーム分けします。各自が選んだ武器を持ったまま結果へ進みます（BANなし）。

### ドラフト後トレード
結果画面で、自チームの武器1枚と相手チームの武器1枚の交換を提案できるオプションです。相手チームの代表者が承認すると成立し、成立回数に制限はありません（ソロではその場で入れ替え）。

### 連戦モード（シリーズ）
1つのルームで複数試合を連続して行うオプションです。BO3（先取2）/ BO5（先取3）から選べ、試合ごとにステージ・ガチルールが変わります。結果画面でホストが勝者を入力すると次の試合へ進み、先取数に達するとシリーズ終了。各試合の編成を一覧できる戦績ボードと、全試合をまとめたシリーズ画像も出力できます。連戦中だけの追加オプションとして、武器ロックアウト（一度ピックした武器は以降の試合で使えない）や、負けチームが次戦のガチルールを選ぶ設定もあります。

### タイマー機能
- ソロ・マルチとも制限時間を設定できます（5〜100秒・既定30秒）。
- 時間切れ時は「確定済み → 仮選択中 → ランダム」の優先順で自動送信します。メンバードラフトや武器ピックのターンにも適用され、時間切れでランダム自動選択されます。

### 確定演出 / 武器読み上げ
ドラフト画面右上のトグルで、BAN/PICK確定時の効果音（🔊）と、確定した武器名の読み上げ（🗣️）を切り替えられます。どちらも既定OFF・端末ごとに保存されます。音はブラウザ内で生成しており、外部ファイルの読み込みや送信はありません。

### 結果画像の保存
- 結果画面の「🖼️ 結果画像を保存」で、ルール・ステージ・両チームのBAN/PICKをまとめた1枚のPNGを生成・保存できます。連戦時は全試合をまとめたシリーズ画像も出せます。
- 画像生成は端末内で完結し（外部送信なし）、個人ピック時はプレイヤー名も併記されます。

### ホーム画面に追加（PWA）
- スマートフォンで「ホーム画面に追加」すると、アイコン付きでアプリのように起動できます。

### その他
- ルール選択（ナワバリバトル / ガチエリア / ガチヤグラ / ガチホコ / ガチアサリ）。「ランダム」はガチ4ルールから抽選します（ナワバリバトルは明示選択時のみ）。
- ステージのランダム選択
- 全11カテゴリの武器に対応（シューター / ローラー / チャージャー / スロッシャー / スピナー / マニューバー / シェルター / ブラスター / フデ / ワイパー / ストリンガー）
- 標準武器のみモード／チーム名カスタマイズ／人数設定（1v1〜4v4）／先攻チーム設定（アルファ / ブラボー / ランダム）
- URLにルームIDが入るので共有が簡単／狭幅のスマホ画面でも崩れにくいモバイル対応

## 使い方

### マルチプレイ
1. ホストが「ホストとして部屋を作る」を選択
2. チーム名・人数・BAN数・ピックモード・ルールなどを設定して「部屋を作る」
3. 表示されたルームIDを参加者に共有
4. 参加者が「部屋に参加する」からルームIDを入力して入室
5. ホストがチーム編成を確認し「ドラフト開始」を押してスタート

> **参加者の退出**: チーム分けの各メンバー横の「×」ボタンをホストが押すと、その参加者をロビーから退出させてモード選択画面に戻せます。

> **同じ端末での再参加**: チーム割り当て済みの参加者が誤ってページを閉じる・再読み込みしても、同じ端末・同じブラウザで再入室すれば元のチーム枠（ピック順割り当て）を引き継いで復帰します。再参加時に名前を変更することもできます。

> **個人ピック・相手ピックのとき**: 両チームとも設定人数が揃わないと「ドラフト開始」ボタンが有効になりません。ロビー画面に現在の参加人数が表示されます。

### 代表者BANの流れ
- ホスト（アルファ代表）とブラボー代表が、同時にBANしたい武器を選んで送信します。
- 相手には「送信済み」とだけ表示され、内容は伏せられます。
- 両方届いた時点で自動公開・確定されます。代表者以外はBAN操作できません。

### 個人BANの流れ
- ピック順上位の各プレイヤーが、それぞれ担当の武器を選んで送信します。
- 味方が送信したBANはBAN中もグリッド・パネルに共有表示され、チーム内での重複を避けられます。相手チームのBANは全員分そろうまで伏せられます。
- 全員分の送信が揃った時点で自動公開・確定されます。

### 同時ピックの流れ（マルチ専用）
- 各ラウンドで「アルファのN番目」と「ブラボーのN番目」のペア2人だけが担当し、同時に武器を選んで「PICKを送信する」をタップします。
- 担当外のプレイヤーはそのラウンド中は操作できず、ペアの選択を待ちます。
- 両方そろうとホスト側に公開画面が表示され、「次へ」で確定すると全員が次ラウンドへ進みます。
- 被りあり仕様（同じ武器を両チームがピックしてもそのまま確定）です。

### 個人ピックの流れ
- 自分のターンになったら武器を選択して送信します。
- ターン外のプレイヤーは他チームの選択を待ちます。
- 全員のピックが終わるとリザルト画面へ進みます。

### 相手ピックの流れ
- ピック順で対応する選手同士がペアになります（例: アルファ1人目 ↔ ブラボー1人目）。
- 自分のターンでは、ペアになっている相手プレイヤーが使う武器を選びます（画面に対象プレイヤー名が表示されます）。
- リザルトには各プレイヤーが実際に使う武器（＝相手に選ばれた武器）が名前付きで表示されます。

### ドラフト中にロビーへ戻る（ホスト専用）
- ドラフト画面のホスト側に「← ロビーに戻る」ボタンが表示されます。
- 押すと確認のうえドラフトをリセットし、ロビーへ戻ります。メンバー情報は保持されるので、設定を変えて即座に再ドラフトできます。
- 参加者側はホストがロビーへ戻ったことを自動検知し、ロビー待機画面へ遷移します。

## セキュリティ

- **Firebase 匿名認証** — サイトを開くと自動でログイン（入力不要）。未認証からの読み書きをブロック
- **Database Rules** — 認証済みユーザーのみ・6文字英数字のルームIDのみアクセス可能
- **ルーム自動削除** — 24時間以上経過したルームをGitHub Actionsで毎日深夜0時（JST）に自動削除

---

## 技術構成

- **フロントエンド**: HTML / CSS / Vanilla JS（単一ファイル構成）
- **リアルタイム同期**: Firebase Realtime Database
- **認証**: Firebase Authentication（匿名ログイン）
- **ホスティング**: GitHub Pages
- **自動削除**: GitHub Actions（毎日実行）
