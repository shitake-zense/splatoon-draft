使い方ガイド

部屋を作って進行する人の操作

  1. 「👑 部屋を作る」から名前を入れて部屋を作成します。
  2. 表示された部屋番号（6桁）か共有URLを参加者に渡します。
  3. ロビーで参加者が揃ったら、チーム（アルファ／ブラボー）への割り当てとピック順を決めます。
  4. ルール設定で 人数(1v1〜4v4)・BAN数・ピックモード・ピック順・ルール／ステージ・武器の絞り込み・お題カード・制限時間 を調整します。
  5. 「ドラフト開始」で全員の画面が一斉にドラフトへ進みます。

ホストはアルファ側の送信担当 兼 進行役です。代表者BAN／代表者ピックでは、ホストがアルファ全員分をまとめて選びます。

設定項目の説明（特に分かりにくいもの）

人数 / BAN数
人数は 1v1〜4v4。BAN数は各チームがBANする武器の数（なし〜各8・既定は各4）。両チーム同じ数です。
ジャンルBAN（武器BANとは別枠）
武器単位とは別の枠で、武器種・サブ・スペシャル単位でまとめてBANできます（例: 「サブ=2」ならサブを2種類まるごと禁止＝そのサブを持つ武器が全て消える）。設定した数は必ずその数だけBANします。代表者BAN相当のとき（個人ピック×個人BAN以外）だけ表示されます。相手ピックでは使えません（枠は表示されません）。
ピックモード（4種・最重要）
個人ピック＝各自が自分の番に自分の武器を選ぶ。代表者ピック＝チーム代表が全員分をまとめて選ぶ。相手ピック＝対になる相手選手の武器を自分が決めて押し付ける（アルファ[N]↔ブラボー[N]がペア）。普段使わない武器を持たされる遊びです。🎲 ガチャ（運命ピック）＝BAN後に各チームへ人数分の武器がランダムで一括配布され、引き直して「確定」するだけ。選ぶ自由のないお祭りモードです。
※ソロでは「通常ピック（＝代表者ピック相当）」「相手ピック」「ガチャ」の3つ。
リロール回数（ガチャ専用）
ガチャで配られた手札を引き直せる回数（チームごと・既定2回）。0にすると引き直し不可＝完全に運だけの配布になります。両チームが「確定」すると即リザルトへ進みます。
ピック順
誰が何番目に選ぶかの並び。交互＝1枚ずつ交互。スネーク＝折り返しで偏りを抑える競技寄りの既定。クラシック／ミドルは折り返し幅違い。バランス／前重ねは 1-2-1 等の固定配分。同時ピックはマルチ専用で、ペアが同時に選んで一斉公開（チーム間は被りOK）。
先攻
最初にピックするチーム。ランダムは開始時に抽選します。
標準武器のみ / 武器の絞り込み
標準武器のみ＝無印だけにし、デコ等のバリアントを除外。武器の絞り込み＝指定した武器種・サブ・スペシャルを持つ武器を候補から消す（例: 強いスペシャルを外してエンジョイ寄りに調整）。どちらも候補が減り、残り数が表示されます。
お題カード / 制限時間
お題カード＝開始時に全32種から縛りを1枚抽選（両チーム共通・非強制で、結果に達成○×を表示）。武器種・サブ・スペシャル・人数など色々な角度のお題があります。制限時間＝5〜100秒。時間切れは「確定済み→仮選択中→ランダム」の順で自動送信します。
ドラフト後トレード
ONにすると結果画面で武器の交換ができます。自チームの武器1枚と相手チームの武器1枚を選んで交換を提案→相手チームの代表者が承認すると成立（拒否も可）。回数は無制限です。マルチでは各チームの代表者だけが提案・承認でき、ソロではアルファ⇄ブラボーをその場で入れ替えられます。
メンバードラフト（キャプテン選抜・マルチ専用）
ONにすると、武器ドラフトの前にチーム分けをキャプテン選抜で行えます。チーム割り当てで各チームのキャプテンを1名ずつ（α／β）に置き、残りは未割り当て（プール）に。両チーム代表者が揃い人数が足りていれば（2v2以上・合計2×人数以上）「メンバードラフト開始」が押せます。開始後は2人のキャプテンが交互にプールから1人ずつ指名（先攻チームが先）。制限時間ONなら時間切れでランダム自動指名。両チームが埋まると選抜完了→そのまま武器ドラフトへ進みます。
連戦モード（シリーズ）
1ルームで複数試合を連続で行います。シリーズ長＝BO3（先取2）／BO5（先取3）。各試合のドラフトが終わったら結果画面でホストが勝者を入力すると、ステージが変わって次の試合のドラフトが始まります。先取数に達するとシリーズ終了で、戦績ボード（各試合の勝者・ルール・ステージ・両チームの編成一覧）が表示され、「🖼️ シリーズ画像を保存」で全試合を1枚のPNGにまとめて保存できます。
連戦のガチルール進行
BO3＝毎試合ガチルールをランダム。BO5＝1〜4試合目をガチエリア→ヤグラ→ホコ→アサリの固定順、5試合目はランダム。
⚖️ 負けチームがルール設定をONにすると、各試合の敗者が次の試合のガチルールを選びます（2試合目以降。1試合目は上記の自動進行）。マルチでは敗者チームの代表者が選び、ソロでは操作者が選びます。
武器ロックアウト（連戦のオプション）
連戦モードONのときに選べます。一度ピックされた武器は、そのシリーズの次の試合以降ずっと使えなくなります（両チーム共有でプールが枯れていく＝後半ほど選択肢が減る独特のメタ）。BANは各試合ごとにリセットされ、ロックアウトの対象はピックされた武器だけです。ドラフト中はロックされた武器が🔒でグレー表示され選べません。

ソロモードについて

「🎮 ソロモード」は1人で両チーム分を操作するモードです。部屋番号は不要で、ピック順や設定の確認・練習に使えます。

部屋に入って遊ぶ人の操作

  1. ホストから受け取った共有URLを開くか、「🚪 部屋に入る」から名前と部屋番号（6桁）を入力して参加します。
  2. ロビーで待機します。チームへの割り当てとピック順はホストが決めます。
  3. ドラフトが始まったら、自分の番でBAN／PICKを選んで送信します。
  4. 操作できるタイミングはピックモードで変わります（個人＝自分の番／代表者＝チーム代表だけ／相手ピック＝対になる相手の武器を選ぶ／🎲ガチャ＝チーム代表が引き直し・確定を担当）。

制限時間が設定されている場合は時間内に送信してください。時間切れ時は確定済み→仮選択→ランダムの順で自動送信されます。

ドラフト後トレードがONのときは、結果画面で各チームの代表者が武器の交換を提案・承認できます（提案が届くと結果画面に表示されます）。

1ドラフトの進行

  1. ロビー … メンバー集合・チーム割り当て・ピック順の確認。
  2. BANフェーズ … 使えない武器を決めます。代表者BANは両チーム同時送信で相手の選択が伏せられます（個人BANも選択可）。武器・武器種・サブ・スペシャル単位でBANできます。個人BANでは味方が送信したBANがグリッドに「味方」マークで共有表示され、チーム内でのBAN重複を避けられます（相手のBANは揃うまで伏せたまま）。
  3. PICKフェーズ … ピック順（交互／スネーク等）に沿って武器を選びます。同時ピックは両チームが選び一斉公開します。🎲ガチャの場合はBAN後に人数分の武器がランダム配布され、各チームが引き直し→「確定」するだけで完了します。
  4. リザルト … 両チームの編成・ステージ／ルール・お題の達成（○／×）が表示されます。ドラフト後トレードがONなら、ここで武器の交換を提案→相手代表者の承認で成立します。
  5. 結果画像を保存 … 端末内で1枚のPNGを生成してダウンロードできます。

メンバードラフト（マルチ専用）がONのときは、ロビーでホストが各チームのキャプテンを1名ずつ選ぶと「メンバードラフト開始」が押せます（2v2以上・人数が揃っているときのみ）。開始後は2人のキャプテンが交互にプールから1人ずつ指名し、両チームが埋まると武器ドラフトへ進みます（制限時間ONなら時間切れでランダム指名）。

お題カードをONにすると開始時に縛りを1枚抽選します（両チーム共通・非強制で、達成は結果に○×表示）。

連戦モード（シリーズ）がONのときは、結果画面でホストが各試合の勝者を入力すると次の試合へ進みます。先取数（BO3=2／BO5=3）に達するとシリーズ終了で、戦績ボード（各試合の編成一覧）とシリーズ画像の保存ができます。ガチルールは BO3=毎回ランダム／BO5=エリア→ヤグラ→ホコ→アサリ→ランダム。「負けチームがルール設定」ONなら2試合目以降は敗者が次のガチルールを選びます。

ドラフト画面 右上の 🔊＝確定音（既定ON）、🗣️＝武器読み上げ（既定OFF）のトグルです。BAN/PICKを確定するたびに効果音が鳴り、読み上げONなら確定した武器名を読み上げます（端末ごとの設定・音は自動生成で外部ファイルなし）。
